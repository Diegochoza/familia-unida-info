Familia Unida

Sistema de Reportes Comunitarios

Empoderamiento Ciudadano

Una solución tecnológica para reportar, visualizar y dar seguimiento a problemas comunitarios, fomentando la colaboración activa entre vecinos y autoridades.

Contexto y Problemática

Muchas comunidades sufren de una desconexión con sus autoridades locales. Según estudios del BID, hasta un 92% de los delitos no son reportados formalmente. "Familia Unida" busca reducir esta "cifra negra" ofreciendo un canal accesible y centralizado para gestionar incidencias, eliminando el subregistro y la desinformación vecinal.

Impacto Esperado

Con la implementación de este sistema, buscamos transformar la gestión comunitaria:

  • Visibilidad Real: Sacar a la luz problemas recurrentes que hoy pasan desapercibidos por falta de un canal formal.
  • Colaboración: Crear un espacio donde el ciudadano deja de ser espectador y se convierte en un agente activo de cambio.
  • Centralización: Evitar la dispersión de información en chats informales, concentrando todo en una base de datos segura.

Categorías de Reporte

El sistema permite clasificar incidencias en 5 áreas clave para la comunidad:

👮‍♂️ Seguridad Pública

Reportes de crimen y vigilancia.

🐕 Maltrato Animal

Atención a fauna urbana y mascotas.

🤝 Vulnerabilidad Social

Apoyo a personas en situación de calle o riesgo.

🚑 Emergencias

Situaciones de riesgo inmediato.

🌳 Medio Ambiente

Saneamiento y cuidado ecológico.

Alcance del Proyecto

La aplicación "Familia Unida" abarca las siguientes funcionalidades técnicas y operativas:

Gestión de Usuarios

Registro, inicio de sesión seguro y manejo de perfiles únicos.

Ciclo de Reportes

Creación, visualización, búsqueda y cambio de estatus (Pendiente a Resuelto).

Interacción Social

Sistema de comentarios integrado para retroalimentación comunitaria en cada reporte.

Evidencia Visual

Capacidad de adjuntar imágenes como prueba en los reportes generados.

Objetivos del Proyecto

Objetivo General

Desarrollar una aplicación de escritorio colaborativa en Java y SQL Server que sirva como prototipo funcional para la gestión de incidencias, estableciendo las bases para futuras mejoras.

Objetivos Técnicos

  • Implementar un sistema CRUD completo utilizando el patrón DAO para el acceso a datos.
  • Garantizar la integridad de la información mediante una base de datos relacional SQL Server.
  • Diseñar una interfaz gráfica intuitiva utilizando la librería Java Swing.
